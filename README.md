# Sysinfo для LinCtrl API

Плагин возвращает сведения о сервере на Windows и Linux. В ответ входят имя сервера, ОС, архитектура, время работы, модель и число логических процессоров, доступная и общая ОЗУ, ёмкость локальных дисков и список обнаруженных видеопроцессоров. Если ОС не сообщает модель процессора или объём ОЗУ, соответствующее значение равно `null`. Пустой список видеопроцессоров означает, что плагин не обнаружил их средствами ОС.

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| GET | `/sysinfo/info` | Сведения о сервере в стандартной JSON-обёртке LinCtrl. |
| GET | `/sysinfo/ping` | Ответ `204 No Content` для измерения задержки HTTP. |

Оба маршрута доступны авторизованным пользователям с ролью наблюдателя и выше.

Соберите нативную библиотеку на целевой платформе, например `dotnet publish SysinfoPlugin/SysinfoPlugin.csproj -c Release -r win-x64`. Для Linux используйте соответствующий RID, например `linux-x64`. Скопируйте содержимое каталога публикации в `plugins/sysinfo` рядом с LinCtrl API.
